# Current Tasks

## Purpose

This document contains the current actionable development tasks.

It is intentionally different from ROADMAP.md.

* ROADMAP.md = where the project is going
* TASKS.md = what should be worked on now

---

# Rules

1. Keep this file focused on current work.
2. Do not duplicate the entire roadmap here.
3. Break large tasks into small actionable items.
4. Mark completed tasks immediately.
5. Remove obsolete tasks.
6. Link to relevant documentation where useful.
7. Do not add speculative features simply because they sound interesting.
8. Prioritize a small number of active tasks.
